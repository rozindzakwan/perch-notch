The bundled files are subsets of these (Latin incl. Vietnamese, Greek, Cyrillic,
punctuation and symbols; no OpenType layout features or hinting), made with
scripts/subset-fonts.sh using fontTools, so fontdue does not keep thousands of
unreachable alternates in memory. SIL OFL 1.1 permits modified versions; Inter
has no Reserved Font Name.
